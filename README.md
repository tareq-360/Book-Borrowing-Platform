Project Name : Online book borrowing platform.....


Purpose : book borrowing by online and try easy learning process....

Live URL : https://book-borrowing-platform-seven.vercel.app/


KEY Features....

User Authentication System: Secure user login and registration workflow to personalize the experience.

Dynamic Announcement Bar: Real-time ticker/banner at the top displaying new arrivals, announcements, and special membership discounts.

Book Discovery & Search Bar: Integrated search functionality allowing users to quickly find books by title.

Categorized Book Catalog: Grid-based book cards categorized by genres (e.g., Story, Tech) displaying cover art and live availability counts.


Frontend Framework & Core....

react / react-dom — Core UI rendering library.

next (or react-router-dom for React SPA) — Server-side rendering, routing, and page management.

UI & Styling

tailwindcss — Utility-first CSS framework for layout and dark theme styling.

@heroui/daisyui  Pre-designed UI components for cards, buttons, badges, and modals.

react-icons / lucide-react — Scalable icons used across navigation, search, and action buttons.

Authentication & Security

better-auth  — User authentication management for login, signup, and profile sessions.

Database & Backend Integration

mongodb — for connecting and querying MongoDB collections (Books, Users, Borrowing logs).


Interactive Components & UX

react-fast-marquee-

Animate.css,-Interactive sliders/carousels for banners or community feedback.

react-toastify — Pop-up toast notifications for borrow actions, logins, and alerts.
